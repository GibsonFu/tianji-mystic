# 天機玄府 · Tianji Mystic

繁體中文互動式命理文化探索網站，結合紫微斗數、姓名學、五行、西洋星座、生肖、易經與數字命理。

## Preview

GitHub Pages（啟用後）：https://gibsonfu.github.io/tianji-mystic/

## 功能

- 深藍紫星空與金色命理盤、五行光球動態
- 行動裝置／桌面自適應設計
- 國曆轉農曆（使用瀏覽器 Intl 中文農曆）
- 紫微斗數：命宮／身宮／十二宮定位，**不包含**十四主星、四化及大限
- 姓名學：使用者輸入經字典查核的筆畫，計算五格；**不會**自行猜測筆畫
- 五行：相生相剋結構
- 星座：日期區間的太陽星座近似值，**不是**完整出生星盤
- 生肖：農曆新年換算，並提示立春流派差異
- 易經：三枚銅錢六次擲卦、六十四卦、動爻及之卦
- 數字命理：生日數字縮減，保留 11、22、33

## 本機執行

本專案目前為無後端的單頁靜態網站，不需安裝 Node.js。

開啟 `index.html` 即可在現代瀏覽器預覽。亦可使用任何靜態伺服器在本機測試。

## GitHub Pages 部署

1. 在此儲存庫前往 **Settings → Pages**。
2. 在 **Build and deployment → Source** 選擇 **Deploy from a branch**。
3. 選擇 **main** 與 **/(root)**，按 **Save**。
4. 等待 GitHub Pages 完成首次發布，然後開啟上方 Preview URL。

後續提交到 `main` 的靜態內容通常會觸發重新部署。

## 重要限制

目前是可以操作的公開網站 MVP，並非完整的商業命理平台或專業排盤服務。完整紫微安星、四柱八字、真太陽時、精密占星與會員系統尚未完成。命理內容屬傳統文化探索與娛樂，不應視為具有科學證據的預測。

**隱私**：本版使用者輸入僅在瀏覽器記憶體中處理，網站未設置收集出生資料的 API 或後端儲存。不代表第三方靜態託管平台不會保留一般連線日誌。

## 技術

HTML5 / CSS3 / Vanilla JavaScript，無外部執行依賴。
